# ATM Interface

A console ATM simulation with Withdraw, Deposit and Check Balance.

Built for the SAM AI Technologies Java Programming Internship.

## How to run

You need JDK 8 or newer.

```
javac ATM.java
java ATM
```

## Notes

- Demo PIN is `1234` (3 attempts), starting balance is Rs. 5000.
- Validates amounts and checks for sufficient balance before withdrawal.
